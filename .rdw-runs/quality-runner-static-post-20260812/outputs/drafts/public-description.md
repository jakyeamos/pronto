Quality Runner turns a team's engineering standards—skills, guides, and agent
rules—into reviewed, repository-scoped checks and rubrics, so the findings
reflect what that team actually values. In a historical Tenure audit, eight
relevant standards packs produced 4,022 raw findings; working with a reviewing
agent, Quality Runner preserved the evidence while source changes and explicit
dispositions reconciled the result to 537 retained raw rows and 0 open
actionable findings. The result is a measurable debt plan with provenance
attached—not a claim that every scanner row was a defect, that the current
checkout passes, or that the case study is deployed.
