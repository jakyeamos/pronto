# Showcase local-fix audit

Reviewed: 2026-08-14.

The remaining showcase work is now represented as one local material-fix pass,
not a repeated project-by-project deferral list. The generated
[`postability-ledger.json`](postability-ledger.json) records a `local_fix` for
each of the 32 active projects with six slots:

1. story route;
2. evidence bundle;
3. no-auth case source;
4. crop-safe preview;
5. short copy; and
6. role/claim review.

`local_fix.state` is `complete` only when all six slots exist in the local
package. `local_fix.remaining` is the exact missing material list when it is
not. This is a material receipt, not a product or publication receipt: installed
runtime behavior, owner/provider authority, hosted no-auth access, and external
destination readbacks remain separate predicates in each project's route plan
and postability row.

The two owner-excluded packets (AI Workflow Leverage and Marketing Autoresearch)
remain available as supporting work but are intentionally absent from the active
postability ledger. The local fix pass does not authorize external posting.
