# Mac Control Showcase packet

This directory is the reviewed source package for Mac Control's AI Showcase
materials. It is not a publication record and does not grant submission
authority.

The canonical story target is the [Mac Control section](../ideal-demo-targets.md#mac-control)
of the AI Showcase ideal demo document. This package owns the capture plan,
copy, evidence, and final assets for that target.

**Current route stage:** `gap_closure`. The aspirational storyboard and
build-gap specification are complete in [route-plan.md](route-plan.md). The
existing script is an evidence-bounded baseline, not the creative ceiling or a
rehearsal commitment.
