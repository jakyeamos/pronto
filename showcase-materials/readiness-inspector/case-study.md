# Readiness Inspector: ready for what?

Readiness Inspector turns a release question into a versioned set of individual checks. The W5 local fixture records a passing test, a failed dependency audit, a blocked publish action, and an unsupported missing profile without creating an aggregate score.

The packet is intentionally bounded. It proves target-bound check receipts and next actions locally. Quality Setup and Evidence Replay projection, stale/profile-version breadth, hosted proof, and external publication remain open gates.
