# Readiness Inspector: ready for what?

Readiness Inspector turns a release question into a versioned set of individual checks. The current-dev profile records target-bound passing receipts, rejects an unknown check as unsupported, and blocks a mutating check without creating an aggregate score. Source tests preserve the failed-check path as a distinct outcome.

The packet is intentionally bounded. It proves target-bound check receipts, explicit unsupported/blocked outcomes, and a reviewed binary preview locally. Quality Setup and Evidence Replay projection, stale/contradictory/not-applicable breadth, native follow-up, hosted proof, and external publication remain open gates.
