# Portable Agentic Workbench: carry safety contracts across hosts

## The case

The case starts with the public `safe-tool-guards` workflow. Its manifest names
two allowlisted files—`CONTRACT.md` and `WORKFLOW.md`—and declares no
dependencies. The demo keeps that small scope visible instead of presenting a
whole skills catalog as if it were one install.

Two clean target roots then run the same sequence: preview, apply, refuse an
overwrite, and recover from the receipt. Generic and Codex produce the same
relative destinations and file hashes, while Codex registration remains an
explicit manual-review boundary. The recovery appendix removes only unchanged
receipt-owned files; a modified file blocks and an unrelated sentinel survives.

## Where the proof stops

The important open edge is PW-4. The repository deliberately has no executable
generic host, and its public contract does not permit provider-backed execution
or host registration. The runtime comparison therefore records unavailable or
blocked probes for positive, negative, and manual-registration scenarios. The
package does not turn matching install files into a claim of equivalent agent
decisions or host behavior.

The fixture is a reproducibility appendix, not a customer deployment. It gives
the public story a concrete safety boundary while preserving the distinction
between portable files, provider adapters, and host-managed state.
