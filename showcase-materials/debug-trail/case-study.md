# Debug Trail: leave the question behind

Debug Trail is a local-first investigation workbench for the moment after a
debugging session gets interrupted. It keeps the question, the declared
experiment, the bounded evidence, and the next action together so an inheritor
does not need to reconstruct the author's mental state.

## The local W1 case

The fixture investigation begins with a concrete hypothesis: **the
deterministic fixture check passes**. Before anything runs, Debug Trail shows
the command, its repository target, read-only mutation class, and expected exit
code. A human explicitly authorizes the action.

The command passes. The receipt keeps a bounded excerpt, redacts the token-like
value, stores a full-output hash, records the source location, and names the
next rerun condition. The result is not just a green terminal line; it is a
target-bound continuation artifact.
