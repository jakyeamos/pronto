# Fleet Radar: keep the fleet honest

Fleet Radar reads an explicit registry and turns each repository's native receipt into a visible freshness and attention state. The local case shows one fresh passing repository beside one failed stale repository, then repeats the refresh while leaving both refs unchanged. The follow-up slice validates the shared evidence envelope and supported producer receipts, attaches a native source-location or local-receipt link to unresolved checks, and preserves unavailable, duplicate, unreadable, mixed-schema, dirty, and refresh-race states.

The packet is intentionally bounded. It proves local read-only projection, explicit identity, contract classification, native-link metadata, and broad local failure handling. Real producer parity, direct native-tool navigation, hosted proof, and external publication remain open gates.
