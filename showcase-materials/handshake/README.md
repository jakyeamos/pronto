# Handshake first-wave packets

Pre-CR Suite, Terrace, and Quality Runner are posted to the Handshake AI
showcase with repository links and Handshake-generated previews. Their local
case pages remain unhosted. Context Compiler Contract is present in the
Handshake profile Projects section, but its AI showcase submission is blocked:
Handshake rejected SVG, PNG, and JPEG chooser uploads with the same generic
error even though Chrome's file-URL setting was already enabled. No duplicate
showcase submission was created.

The packet format keeps the three required materials together:

1. a crop-safe 16:9 preview;
2. a description of 500 characters or fewer; and
3. a no-auth demo or case-study link, which remains a publication gate until a
   hosted URL is verified.

The optional video branch is deliberately absent. A static page and linked
proof are enough when they make the same bounded claim.

at a small size and confirm that each local demo page still points to the same
evidence. Only after that should a public host and Handshake URL be chosen.

links with hosted case-study URLs requires a verified no-auth host and a fresh
readback at desktop and mobile widths.
